## Risks

1. **`#labelRender` 与 `show-search` 共存**：Select 开启搜索时，`labelRender` 仅在 dropdown 关闭且有选中值时渲染，不影响搜索输入。风险低。
2. **Tooltip 包裹导致 Select 内部布局变化**：`#labelRender` 渲染的 div 必须在 Select 内部容器内，不能额外嵌套影响 flex 布局。需要用 `display: block; overflow: hidden`。
3. **version-info 的链接渲染**：部分 `.info-item__value` 内含 `<a>` 链接元素（客户分级/产品分级版本跳转），链接已有 `class="link-text"` 样式，需在链接外包裹 Tooltip 并保持可点击。
4. **`#tagRender` 的多选 tag 关闭按钮**：自定义 `tagRender` 时必须保留 `closable` 和 `onClose` 功能，否则用户无法手动删除已选项。

## Non-goals 确认（不修改）

- 不修改 filter-bar 中非版本/手套的其他 Select
- 不修改 Select 的 `max-tag-count` 值
- 不新增package/utility
