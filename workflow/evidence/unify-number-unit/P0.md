# 统一数字单位转换方法

## Scope — 涉及文件

| 文件 | 改动 |
|---|---|
| `packages/@core/base/shared/src/utils/money.ts` | 删除 `formatMoneyAutoUnit`、`MoneyAutoUnit`；保留 `formatNumberAutoUnit` 作为唯一方法 |
| `apps/main-app/src/views/order-grading/customer/components/kpi-grid/index.vue` | `formatMoneyAutoUnit` → `formatNumberAutoUnit`；内联 `quantityOf` → `formatNumberAutoUnit` |
| `apps/main-app/src/views/order-grading/product/components/kpi-grid/index.vue` | 同上 |
| `apps/main-app/src/views/tracking-monitoring/warning-management/components/TargetDeviationTab.vue` | `formatMoneyAutoUnit` → `formatNumberAutoUnit`；删除 `formatMoney` 包装 → 用 `formatNumberAutoUnit` + 调用方拼接 "元" |
| `apps/main-app/src/views/tracking-monitoring/warning-management/components/WarningDetailModal.vue` | 同上 |

## Non-goals

- 不改动 `formatNumberAutoUnit` 的阈值逻辑（≥1万/≥1000万/≥1亿 不变）
- 不改动任何业务逻辑/数据流
- 不改动 CSS/样式

## Risks

1. **API 兼容性风险（中）**：`formatMoneyAutoUnit` 是公开导出，其他未发现的调用点可能还在使用。改前必须全仓库 grep 确认仅上述 4 处使用。
2. **kpi-grid 内联 `quantityOf` 返回值类型变化**：原 `quantityOf` 返回拼接好的字符串（如 "123.46万"），新方案用 `formatNumberAutoUnit` 返回 `{ value, unit }`，需要创建薄包装或调整模板
3. **TargetDeviationTab 中 `getSubtractMeta` 单位拼接**：原 `formatNumber(abs)` → 新格式是 `{ value, unit }`，拼 "元"/"标箱" 时需处理 unit 的组合（如 "需追赶 5 千万标箱"）
