## Scope

### 涉及文件
| 文件 | 改动类型 | 说明 |
|---|---|---|
| `apps/main-app/src/views/tracking-monitoring/warning-management/components/GradeNotifyModal.vue` | 重构 | 弹窗内部从单一 Select 改为五个大区分组 Select；数据模型从 `formRoleCodes` 改为 `regionFormMap`；保存逻辑改为遍历大区批量提交 |
| `apps/main-app/src/views/tracking-monitoring/warning-management/components/GradeWarningTab.vue` | 小改 | 传递 `regionOptions` 给 `GradeNotifyModal` |

### 不涉及（非目标）
- 不修改 `ReceiverConfigModal.vue`（目标偏差预警的接收人配置弹窗保持不变）
- 不修改 `ThresholdConfigTab.vue`（监控阈值配置 Tab 不受影响）
- 不修改 API 层（`getMonitorConfigListApi` / `editMonitorConfigApi` 已支持所需功能）
- 不修改 `types.ts` 中的现有类型定义
- 不新增 API 端点
- 不修改 `index.vue`（父组件传递的 props 已包含 `enumOptions.regionOptions`）

## Risks

| # | 风险 | 缓解措施 |
|---|---|---|
| 1 | API 返回的 configs 数量 ≠ 5（某些大区暂无配置），需要正确处理空态 | 对无 config 的大区使用空 roleCodes，保存时 id 为空字符串（后端可能按 upsert 处理，与现有一致） |
| 2 | 5 个 `editMonitorConfigApi` 调用中部分失败，可能导致数据不一致 | 使用 `Promise.allSettled` 或顺序调用，任一失败则提示用户「部分保存失败」 |
| 3 | `regionOptions` 动态数据在弹窗打开后变化（如重新加载枚举） | 弹窗打开时快照 `regionOptions`，弹窗内不响应外部变化 |
