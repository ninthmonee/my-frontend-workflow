## Risks

1. **基础场景不存在或非 builtIn（中）**：场景列表可能无 `builtIn === true` 项（后端数据异常），导致拿不到全量参数组。
   - 缓解：未找到基础场景 → 回退 constants 硬编码列表，弹窗正常可用。
2. **基础场景详情请求失败/为空（中）**：`getScenarioDetailApi` 失败或 `groups` 为空数组。
   - 缓解：回退 constants；加载期间禁用确认按钮，避免提交空选择。
3. **selectedGroups 默认全选与动态列表脱节（低）**：加载完成前 `resetForm` 若用空 code 列表初始化，会清空用户后续选择；加载完成后需重置为全选。
   - 缓解：`selectedGroups` 在加载完成后统一置为动态列表全部 code；加载中提交按钮禁用。
4. **弹窗复用旧数据（低）**：弹窗每次 show 是全新实例（useModalRef + remove() 销毁），onMounted 重跑，不会复用上一次的列表。
   - 缓解：保持 destroy-on-close 命令式模式，加载逻辑放 onMounted（改前检索确认，不引入 watch(visible)）。
