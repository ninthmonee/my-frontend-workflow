## 摘要

iOS/iPadOS Safari 原生 Fullscreen API 会触发系统"向下轻扫退出"手势 overlay。
方案：封装 `usePlatformFullscreen` composable，iOS Safari 走 CSS 模拟全屏，其他浏览器委托 `@vueuse/core`。

关键要点：
1. iPadOS 13+ 检测需组合 `maxTouchPoints`
2. CSS 全屏 `z-index: 9999`
3. `:fullscreen` 伪类并列 `.is-css-fullscreen` class
4. `:-webkit-full-screen` 需 stylelint disable
