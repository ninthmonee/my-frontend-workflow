## Risks

1. **Select 下拉 z-index 遮挡**（高风险）：CSS 全屏层 `z-index: 9999`，而 `getPopupContainer` 在需求预测页面返回 `document.body`（antdv dropdown z-index 默认 1050）。全屏模式下 Select 下拉会被遮挡。需评估两个策略：
   - 策略 A：降低 `.is-css-fullscreen` z-index 到 < 1050（可能引入其他遮挡问题）
   - 策略 B：`getPopupContainer` 返回全屏目标元素自身（需处理 `overflow: auto` 裁剪下拉问题）
   
2. **产能分配 `getPopupContainer` 与 CSS 全屏冲突**（中风险）：产能分配当前返回 `resultContentRef.value`，CSS 全屏时该元素有 `overflow: auto !important`，可能裁剪 Select 下拉。
   
3. **full-screen.vue 无 target 参数**（低风险）：通用全屏组件传 `undefined` 给 `usePlatformFullscreen()`，CSS 全屏作用于 `document.documentElement`，需验证视觉效果。
