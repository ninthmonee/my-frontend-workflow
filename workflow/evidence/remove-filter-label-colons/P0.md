# P0 Evidence — remove-filter-label-colons

## Scope

**目标**：去除筛选项 label 文本末尾的「：」冒号符号（如「区域：」→「区域」）。

**涉及文件（4 个）：**
- apps/main-app/src/views/tracking-monitoring/target-monitoring/index.vue — 9 处筛选 label
- apps/main-app/src/views/master-data/supply-network/components/control-bar/index.vue — 7 处（产品名称/区域/区域部门/客户等级/工厂/材质 + 展示版本）
- apps/main-app/src/views/order-grading/customer/components/control-bar/index.vue — 8 处（展示版本/区域/区域部门/国家地区/系统分级/分级结果/人工调整/客户名称）
- apps/main-app/src/views/order-grading/product/components/control-bar/index.vue — 11 处（展示版本/材料/品级/颜色/特殊品类/区域/区域部门/系统分级/分级结果/人工调整/产品名称）

**非目标（明确不做）：**
- **保留「更新时间：」「路径数：」**（元信息/统计文本，非筛选项，用户明确说「筛选项」）
- 需求预测/产能分配页面 label 本就不带冒号，无需改动
- 不动「当前激活版本」chip 文案
- 不改任何样式/逻辑，仅删冒号字符

## Risks

1. **误删元信息冒号**：「更新时间」「路径数」也带冒号，若一并删除会破坏元信息展示（用户表述为「筛选项」，需严格区分控件 label）。
2. **遗漏风险**：4 文件 30+ 处，需逐文件 grep 确认全部筛选项 label 均已去冒号、无残留。
3. **展示版本归属**：展示版本是版本选择控件（Select），按筛选项处理去冒号；若用户本意保留需回退（已在 P0 明确并请用户确认）。
