## 需求变更记录（Phase 3 第三轮回退）

- 用户反馈（P3 未解决）：期望库存水位没有数据。
- 根因：`applyDetailTableValues` 通过 `stockingValues.value = rawValues` **整体替换** ref 值；ParamGrid 之前用 `const { stockingValues } = props` **直接解构**，拿到的是替换前的旧对象引用 → 显示层读不到新数据（区域平衡因模板直接访问 props 未解构而正常）。
- 修复：
  - ParamGrid 改用 `toRefs(props)` 响应式解构 `stockingValues`/`stockingColumns`/`stockingLocations`，模板始终指向 props 最新值
  - 库存数据源增强：paramValues 为空时回退 definitions.displayValue（data.md 中为 `{PVC,丁腈}` 对象）；物料列取 paramValues key ∪ definitions.materials 并集

## 需求变更记录（Phase 3 第二轮回退）

- 用户反馈（P3 未解决）：① 区域平衡仍显示硬编码 5 大区（内销/北美/欧洲/日韩/亚太）而非动态 paramValues（data.md 为 14 个中文区域）；② 期望库存水位也需动态渲染；③ 提交格式应与各参数组 paramValues 结构一致。
- 处理（数据完全以 paramValues 为准，彻底移除硬编码驱动）：
  - `regionBalanceRows`：region=中文区域名，完全由 paramValues 构建；初始为空数组；resetOnOpen/applyConstraints 不再用 REGION_OPTIONS 重置
  - `stockingValues`：改为 `Record<string(中文区域), Record<string(物料), number>>`，与 paramValues 结构一致；行列由 paramValues/definitions 动态构建
  - `applyConstraints`：移除区域/库存覆盖（约束接口扁平字段不再套用，以场景 paramValues 为准）
  - `handleOk`：区域提交 `{中文区域名: {min,max}}`、库存提交 `{中文区域名: {物料:值}}`，与 paramValues 一致
  - `version.ts`：`CapacityAllocationGroup.paramValues` 扩展为 `Record<string, string | number | Record<string, number> | {max,min}>`
  - ParamGrid：区域/库存表格空数据时显示占位，不渲染硬编码表格；移除 STOCKING_LOCATIONS/PRODUCTS fallback
  - composable 移除 REGION_OPTIONS/STOCKING_LOCATIONS/STOCKING_PRODUCTS import

## 需求变更记录（Phase 3 第一轮回退）

- 用户反馈：**场景参数详情接口数据未获取到时，不渲染之前硬编码（CREATE_PARAM_GROUPS）的内容**，改为占位元素。
- 处理：移除 CREATE_PARAM_GROUPS 兜底——
  - `paramGridItems`：detailGroups 为空 → 返回空数组
  - `initGroupValues`：detailGroups 为空 → 清空 groupValues
  - `handleOk`：detailGroups 为空 → 提示「场景参数未加载完成」并终止
  - `onScenarioChange` 失败分支：清空 enabledGroupCodes/detailGroups
  - `ParamGrid`：paramGridItems 为空且非 loading → 显示占位「暂无场景参数配置，请选择引用场景」
  - 移除 `CREATE_PARAM_GROUPS` import（composable 中已无引用）

## 风险缓解落地

- Risk 1（data.md 结构）：以 data.md 为准实现 applyDetailTableValues；definitions 缺失时组内空定义渲染
- Risk 2（paramValues 类型放宽）：显式处理库存对象→flat key 提取；区域对象→min/max
- Risk 3（堆叠布局耦合）：保持 6 固定组 + 4 列布局规则，仅字段渲染动态化
- Risk 4（默认选中触发链）：loadScenarios 仅空值时设置内建场景，主动调 onScenarioChange
