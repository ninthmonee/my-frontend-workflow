# P0 Evidence — unify-filter-style-4pages

## Scope

**目标规范（客户分级单个筛选项样式，依据 css.md「筛选项 label 等宽对齐」）：**
1. label 文本区域等宽：`width: 5em; flex-shrink: 0`（font-size 12px）
2. 普通筛选 Select 等宽：170px
3. 版本选择控件（当前版本/多版本对比）：**保持现有宽度**（240/260px，用户已确认，对应客户分级「展示版本 280px 例外」）

**涉及文件（5 个）：**
- apps/main-app/src/views/demand-forecast/version-management/components/header-bar/index.vue — 起始月份 160→170，label 等宽
- apps/main-app/src/views/demand-forecast/forecast-results/components/header-bar/index.vue — 起始月份 160→170，label 等宽；当前版本 240 保持
- apps/main-app/src/views/demand-forecast/forecast-results/components/tab-container/index.vue — 10 个筛选：普通（区域/区域部门/材料/客户分级/产品分级/利润档位/手套产品/多版本对比 tab 材料）130-160→170；多版本对比 260 保持；label 等宽
- apps/main-app/src/views/capacity-allocation/allocation-results/components/header-bar/index.vue — 决策年份 160→170，label 等宽；当前版本 240 保持
- apps/main-app/src/views/capacity-allocation/allocation-results/components/tab-container/index.vue — 21 个筛选：普通（共用 8 个 + 需求满足 7 个 + 内销 5 个中非版本类）120-160→170；多版本对比 260 保持；label 等宽

**label 类名映射：** `.month-filter__label` / `.field-filter__label` / `.filter-bar__label`（各文件独立 scoped，分别加样式）

**非目标（明确不做）：**
- 不改筛选栏卡片化背景结构（`.filter-bar__item` 布局保持，仅加 label 等宽样式）
- 不改已有 tooltip（手套产品/当前版本等已就位）
- 产能分配-版本管理页面无筛选项，跳过
- 不动版本管理表格/弹窗内控件
- 不新增/删除/重命名筛选项

## Risks

1. **类名分散**：5 个文件 3 种 label 类名，需逐文件定位，遗漏任一文件会导致该页面对齐不一致。
2. **窄屏换行**：Select 统一 170px 后，iPad 竖屏/窄屏下筛选栏换行布局变化（flex-wrap 自动换行，无破坏性，需人工确认视觉）。
3. **版本控件边界**：用户确认版本控件保持宽度，但各页版本控件宽度不一（240/260px），属既有设计不强制统一。
4. **改动量大**：约 30+ 处 Select 宽度取值修改，需 grep 验证无残留旧宽度（120-160px）。
