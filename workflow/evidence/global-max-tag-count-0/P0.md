## Risks
- **R1（布局溢出）**：max-tag-count 0 使已选标签全部展开，窄屏/多选情况下筛选栏可能变高或换行。→ 缓解：所有筛选栏均为 flex-wrap 布局（`filter-bar`/`filter-bar__item`），标签展开只增加高度，不破坏布局；风险低、可逆。
- **R2（机械替换误伤）**：27 处替换需保证全部落在多选 Select 上（已检索确认 3 文件 max-tag-count=1 与 mode=multiple 数量一一对应 9/9、13/22、5/5）。→ 缓解：按文件逐一替换并最终 grep 校验无残留 `"1"`。
- **R3（视觉一致性）**：同一页面内 0 与 1 并存会不一致——本改动后全项目统一为 0，一致性反而提升。
