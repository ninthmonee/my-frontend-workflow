### GradeNotifyModal.vue 改动详情

**数据模型**
- `GradeNotifyModalArgs` 新增 `regionOptions: Array<{ label: string; value: string }>`
- 新增 `RegionConfig` 接口（id / roleCodes / status / builtIn）
- 新增 `RegionConfigItem` 接口（zone + label + config 三元组）
- `formRoleCodes` / `savedConfigId` / `savedStatus` / `savedBuiltIn` → `regionConfigs: ref<RegionConfigItem[]>`

**生命周期**
- `watch(() => args.value, ...)` + `{ immediate: true }` → `onMounted(async () => {...})`
- 组件每次关闭调用 `remove()` 销毁，下次打开重新挂载，`onMounted` 中 `args` 已有值
- 先同步 `initEmptyConfig(regions)` 保证弹窗打开立即渲染，再异步 `getMonitorConfigListApi` 回填

**保存逻辑**
- `onOk`: `Promise.allSettled` 遍历 `regionConfigs`，每个大区独立 `editMonitorConfigApi`
- 部分失败：`message.warning` 提示失败数
- 全部成功：`message.success`

**模板**
- `:description` — 按 kind 动态显示说明文字
- `v-for="item in regionConfigs"` — 五个大区分组
- 每个大区独立 `FormItem(:label=item.label)` + `Select(mode="multiple")`
- Modal width: 560px → 640px
