### 非目标（明确不做）
- 不改 `use-columns.tsx` 中的 `emit('update:row', ...)` 调用（没有对应 prop，不是 defineModel 候选）

- 不调整任何业务逻辑或 API

## Risks

1. **Pagination 写入路径遗漏**：`common-antv-table` 中 `handlePageChange`/`handlePageSizeChange` 通过 `paginationConfig.value = {...}` 赋值，改为 defineModel 后需改为 `pagination.value = {...}`
2. **selectedCustomerId 回调链断裂**：`customer-table/use-columns.tsx` 第 585 行 `emit('update:selectedCustomerId', code)` — emit 通过回调传入，改为 defineModel 后调用方式需同步调整
3. **全局 typecheck 失败**：迁移 13+ 文件后剩余 emit('update:xxx') 声明和旧 prop 引用可能残留，需先 typecheck 后逐条修正
