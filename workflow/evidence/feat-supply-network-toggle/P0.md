## Risks

1. **后端 `enabled` 字段未返回**：`SupplyNetDetailRow` 目前没有 `enabled` 字段，需确认后端接口已返回该字段。若后端未返回 → Switch 切换后列表刷新会丢失状态。
   - 缓解：API 返回数据使用 `(res as any).data ?? res` 兼容多种格式，新增字段不会破坏现有逻辑
   
2. **Switch 触发 change 事件时机**：Switch 切换会立即触发 change，需要 @change 中调用 toggle API 并刷新列表。若 API 失败需回滚 Switch 状态，避免 UI 与实际状态不一致。

3. **批量操作按钮过多**：新增两个批量按钮后，toolbar 空间可能拥挤（现有：已选 N 项 + 批量删除；新增：批量启用 + 批量停用）
