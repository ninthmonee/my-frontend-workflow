## 候选沉淀点

### 1. 弹窗数据预取 + 模块级幂等缓存（推荐，state/api domain）

**现象**：创建场景弹窗参数组列表从「每次打开请求接口」演进为「页面加载时预取、弹窗读缓存」，避免打开弹窗的请求延迟与名称闪烁。

**核心模式**：模块级单例缓存（ref + loadPromise 幂等），页面数据加载成功即预取，弹窗 `onMounted` 只 await 同一 Promise：

```ts
// useBaseScenarioParamGroups.ts
const paramGroups = ref<ScenarioGroupOption[]>([]);
let loadPromise: Promise<void> | null = null;
export function loadBaseScenarioParamGroups(): Promise<void> {
  if (loadPromise) return loadPromise;
  loadPromise = (async () => { /* 列表找 builtIn → 详情 groups → 缓存 */ })();
  return loadPromise;
}
export function getBaseScenarioParamGroups() { return paramGroups; }
```

**关键坑位**：
1. 静态回退占位会「闪烁」——先显示硬编码名称再替换为动态名称，应改为：初始为空 + 加载态 + 空态兜底（v-if/v-else-if/v-else 三态）
2. `loadPromise` 必须模块级（非组件级），否则每次打开弹窗仍会重新请求
3. destroy-on-close 弹窗每次 show 是新实例，`onMounted` 即可，无需 watch(visible)

**验证**：typecheck + build 全绿；弹窗打开 Network 无新请求。

## 推荐理由

候选 1 是「弹窗数据预取 + 模块级幂等缓存」可复用模式（state/api domain），本仓库 modal 经验库有生命周期模板但无预取缓存条目，值得沉淀。
