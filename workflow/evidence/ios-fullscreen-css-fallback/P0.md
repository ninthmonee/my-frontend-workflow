## Risks

1. **iPadOS 检测不可靠**：iPadOS 13+ UA 伪装为 Mac，若仅靠 UA 检测会漏判。对策：组合 `maxTouchPoints >= 1` + `navigator.platform` + UA 多重判断，参考 WebKit 官方 recommendation
2. **CSS 全屏层级冲突**：CSS 模拟全屏使用 `position: fixed; z-index` 可能与 antdv-next 弹窗/modal 的 z-index 栈冲突。对策：使用极高的 z-index（如 9999）并在模板中设置合理的 append-to 策略
3. **:fullscreen 伪类失效**：CSS 模拟全屏不会触发原生 `:fullscreen` 伪类和 `::backdrop`。3 个页面级组件使用了 `:fullscreen` / `:fullscreen::backdrop` 样式。对策：composable 返回统一的状态 ref，组件绑定 class（如 `.is-css-fullscreen`）替代 `:fullscreen` 伪类
4. **Android 全屏行为**：CSS 模拟全屏无法隐藏 Android 系统导航栏（原生 API 可以）。对策：Android Chrome 走原生 API，仅 iOS/iPadOS Safari 走 CSS 降级
